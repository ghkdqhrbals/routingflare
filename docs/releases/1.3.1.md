## Fixed

- Replace manual HTTP forwarding with a bundled streaming reverse proxy. No extra runtime installation is required.
- Preserve WebSocket upgrade negotiation, subprotocols, compression, binary/text frames, ping/pong, and close frames.
- Fix split and chunked uploads, request/response trailers, incremental responses, and cancellation propagation.
- Preserve Host, Origin, Authorization, cookies, redirects, and origin error responses without buffering entire bodies.
- Recheck route security on every HTTP request, including after rejected WebSocket upgrades and on reused connections. Failed policy synchronization closes the affected proxy instead of leaving outdated access rules active.
- Close active streams when the proxy stops or its owner exits, and report proxy failures in route status.

## Verified

- 65 Swift tests and 20 local protocol tests, including Go race checks, real WebSocket clients, HTTP/2, and native gRPC against an h2c local server.
- Release-built Swift host with the bundled proxy, plus a real Cloudflare WebSocket handshake, message round trips, and close. The public smoke test used a test-only DNS resolver; system DNS settings were not changed.

## Compatibility

- SSE requires a named DNS tunnel; Cloudflare Random DNS does not support SSE.
- Native gRPC works through the local proxy, but Cloudflare Tunnel public hostnames do not support native gRPC.
- Network outages and Cloudflare limits still apply. Existing authorized streams remain connected across security changes; new requests use the updated policy.

See [protocol support and limitations](https://github.com/ghkdqhrbals/routingflare/blob/v1.3.1/docs/proxy-design.md).
